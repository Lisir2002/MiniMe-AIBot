# 快速上手

从安装到完成第一条 AI 对话。如需先观看操作演示，参见[视频教程](appdoc://guide/video-tutorials)。

## 系统要求

- Android 8.0（API 26）及以上
- arm64-v8a 真机（模拟器或其它架构暂不支持）

## 下载安装

官网中文首页为 `/`，英文页面为 `/en/`，可以直接访问或分享对应地址。电脑上可在顶部导航点击「EN」前往英文页面；手机上先打开右上角菜单，再选择「English」。选择「中文」可返回中文页面。页面语言由访问地址决定，与 App 内的语言设置相互独立。

从 [GitHub Releases](https://github.com/Lisir2002/MiniMe-AIBot/releases/latest) 下载 MiniMe-Code 安装包。当前仅提供 **arm64 真机包**（`minimecode-arm64-<版本>.apk`），适用于 arm64-v8a 架构的安卓真机，已启用 R8 混淆并使用正式签名。

**【注意】架构要选对**

> MiniMe-Code 仅适配 arm64-v8a 真机，模拟器或其它架构无法运行内置容器。


在「设置 → 关于 → 检查更新」中可在 App 内直接下载并安装匹配的安装包；也可到 Release 页面手动下载。

## 1. 配置 AI 供应商

**【提示】首次启动有新手引导**

> 首次启动时会自动开启新手引导（1.12.0 新增），依次引导完成下面几步；也可随时点击「跳过」，或之后在「设置 → 重新运行新手引导」再次启动。


MiniMe-Code 自身不提供模型，需要先接入一个模型服务。

1. 点主页左上角菜单按钮打开侧边栏，点底部「设置」。
2. 进入「AI 配置 → AI 供应商」，点右上角 + 新建，在「配置」标签填写四项：
   - **名称**：别名，例如「官方 OpenAI」。
   - **上游格式**：`OpenAI` / `Anthropic` / `Gemini` 三选一。第三方中转站一般选 `OpenAI`。
   - **API Key**：你的密钥，形如 `sk-xxx`。
   - **Base URL**：API 根地址，**留空时按上游格式使用官方地址**；用第三方中转时填入中转服务的地址。
3. 底部切到「模型」标签添加模型：
   - 点击「拉取模型」从服务端同步可用列表，点击每行右侧的「+」逐个添加，或用右上角「全部添加」一键加入。
   - 点击右上角 + 手动输入模型名（例如 `gpt-4o`）。中转站模型名拉取不全时使用此方式。
   - 可选：点击模型行编辑元数据（上下文窗口、价格、图片输入与工具调用等能力开关）。

填完退出编辑页时会自动保存，没有单独的保存按钮。

## 2. 选择模型

回到聊天主页，点击输入框下方工具栏的模型按钮，在弹窗中选择刚添加的模型。顶部搜索框可以筛选，模型按供应商分组显示，点击分组标题可以折叠或展开。

## 3. 准备执行环境

默认使用内置的本地容器，无需任何配置。第一次使用时，在主页点击进入终端，按提示完成一次初始化即可（解压系统、安装基础工具），之后 AI 就能正常执行命令。

如需把远程服务器当执行后端，见[远程 SSH 模式](appdoc://guide/remote-ssh)；容器与镜像的详细设置见[容器与镜像](appdoc://guide/container)。

## 4. 开始对话

在输入框输入内容后点击发送。输入框下方工具栏最左侧的模式按钮可以在 BUILD、PLAN、AUTO 之间切换，区别见[三种模式](appdoc://guide/modes)。

## 实用贴士

- 在主页空会话中选择的模型将被记录为新会话的默认模型，后续新建会话自动沿用。
- 识图、生图与标题总结支持独立指定专属模型，详见[默认模型](appdoc://guide/default-models)。
- AI 修改代码前会自动创建快照，支持一键安全回滚，详见[检查点与撤销](appdoc://guide/checkpoint)。
- 执行编译等耗时任务前，建议开启[软件权限](appdoc://guide/app-permissions)中的后台运行保活，防止系统在切换后台时终止进程。
